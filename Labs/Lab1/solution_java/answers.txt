Part 4. Reason about your implementation
----------------------------------------

4. How many comparisons would firstIndexOf need for 1,000,000,000,000 elements?
   (This is way too big for your computer's memory!)

Every comparison cuts the search range in half.
Since log_2(1,000,000,000,000) is just below 40, we need 40 comparisons.


Alternative answer:
The number of comparisons is logarithmic in the array size.
Squaring the array size doubles the needed number of comparisons.
So from 20 comparisons for 1,000,000, we get 40 comparisons for 1,000,000,000,000.
